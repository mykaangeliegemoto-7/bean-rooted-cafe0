# Bean Rooted Café Website

A responsive, interactive café website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder (not the ZIP).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site.

All photos are stored locally in `assets/`, so they travel with the website. Menu descriptions are showcase copy; confirm actual menu items, prices and availability with the café before publishing.
